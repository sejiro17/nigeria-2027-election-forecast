# Nigeria 2027 Presidential Election Forecast

A data analysis project estimating each candidate's chances in Nigeria's January 2027 presidential election, and explaining why.

## Goals
- Collect and clean past election results, the 2027 voter register, polls and economic indicators
- Model win probabilities, including the 25% in two-thirds of states rule
- Build an interactive Tableau Public dashboard

## Project structure
- `data/raw` – original downloads, never edited
- `data/cleaned` – cleaned versions
- `data/final` – Tableau-ready tables
- `notebooks` – cleaning and analysis work
- `docs` – sources log and methodology notes
- `tableau` – dashboard files
